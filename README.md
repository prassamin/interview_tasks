# SM Technology Interview Task

This project was built as part of the frontend interview task.

## Tech Stack

- Next.js
- React
- TailwindCSS
- Framer Motion
- GSAP

## Installation

git clone -b sm_technology https://github.com/prassamin/interview_tasks.git
cd sm_technology
bun install
bun run dev
